Overview

This project turns the core ideas behind binary distillation into an interactive visual model. Ethanol is more volatile than water, so repeated vaporization and condensation enrich the vapor moving upward through the column while the liquid moving downward becomes more water-rich.

The controls are designed to make the tradeoffs visible: higher product purity generally requires more separation work, while increasing reflux can reduce the number of ideal stages needed at the cost of returning more liquid through the column.

The model is an educational estimate inspired by equilibrium-stage methods. It is not intended for equipment sizing, safety decisions, or production design.

Engineering concepts

The simulator uses a simplified relative-volatility relationship for the ethanol-water system and a Fenske-style estimate for the minimum number of theoretical stages. A reflux adjustment then provides an intuitive operating-stage estimate for comparing scenarios.

In a full process design workflow, this starting point would be extended with measured vapor-liquid equilibrium data, feed thermal condition, material balances, energy balances, tray efficiency, pressure effects, and a McCabe-Thiele or rigorous equilibrium-stage solution.
