How it works

From landmarks to a label

The camera frame is passed through MediaPipe Hands, which returns 21 landmarks for each detected hand. The recognizer compares fingertip and joint positions to estimate which fingers are extended, then applies the same gesture priority used in the Python version.

The canvas is only a visualization layer: the colored connections show the hand skeleton, while the output panel reports the recognized gesture. Camera processing stays in the browser after the page loads.

Camera access requires permission and usually works only on HTTPS or on a local development server. No camera frames are uploaded by this demo.
